Kali Linux 한글 입력,
apt 한 줄로 끝.

ibus·fcitx 설치도, 설정 파일 편집도 없습니다. Rust로 만든 두벌식 한글 입력기와 무료 한글 글꼴을 한 번에 설치합니다.

curl -fsSL https://agnusdei1207.github.io/hangul-setting/install.sh | sudo sh

설치

  1. 위 명령을 터미널에 붙여 넣습니다. 저장소 서명 키 등록, apt install, 글꼴 설치까지 자동으로 합니다.
  2. 로그아웃했다가 다시 로그인합니다.
  3. 한/영, 오른쪽 Alt, Shift+Space 중 하나로 한글을 켭니다.

되는 곳

  • 터미널qterminal, xfce4-terminal, xterm
  • 브라우저Firefox, Chromium
  • GTK3 · GTK4 앱Mousepad, 파일 관리자 등
  • Qt6 앱Wireshark 등

한/영 상태는 모든 앱이 함께 씁니다(GTK4 앱은 앱마다 따로). 대상은 Kali 기본 데스크톱인 Xfce(X11), amd64입니다.

한/영 전환 키 바꾸기

~/.config/hangul-setting/config에 한 줄을 적고 다시 로그인합니다. 쉼표로 여러 개를 지정할 수 있습니다.

toggle = Ctrl+space, Hangul

쓸 수 있는 이름: Hangul, Alt_R, Control_R, Super_R, Caps_Lock, Menu, space, F1~F12, 글자 한 개. 앞에 Shift+, Ctrl+, Alt+, Super+를 붙일 수 있습니다.

직접 저장소 등록하기

스크립트를 쓰지 않으려면 아래 세 줄이 같은 일을 합니다. 패키지는 GPG로 서명되어 있습니다.

sudo curl -fsSL https://agnusdei1207.github.io/hangul-setting/hangul-setting.gpg -o /usr/share/keyrings/hangul-setting.gpg
echo "deb [signed-by=/usr/share/keyrings/hangul-setting.gpg] https://agnusdei1207.github.io/hangul-setting ./" | sudo tee /etc/apt/sources.list.d/hangul-setting.list
sudo apt update && sudo apt install hangul-setting

업데이트는 평소처럼 sudo apt upgrade로 받습니다.

삭제

sudo apt purge hangul-setting
sudo rm /etc/apt/sources.list.d/hangul-setting.list /usr/share/keyrings/hangul-setting.gpg

자주 묻는 질문

ibus나 fcitx를 설치해야 하나요?

아니요. hangul-setting은 Rust로 만든 독립 입력기라 ibus·fcitx 패키지나 데몬이 필요 없습니다. 이미 ibus가 깔려 있어도 함께 동작합니다.

한글이 네모로 깨져 보여요.

설치할 때 무료 나눔 글꼴(OFL)이 함께 설치되어 한글이 바로 보입니다. 터미널용 D2Coding 글꼴도 들어 있습니다.

입력이 안 돼요.

설치 후 다시 로그인했는지 확인하세요. 로그인 없이 바로 쓰려면 터미널에서 hangul-setting &를 실행한 뒤 앱을 새로 엽니다.

Wayland에서도 되나요?

Kali 기본 데스크톱인 Xfce(X11)를 대상으로 합니다. Wayland 세션의 네이티브 앱은 지원하지 않습니다.
